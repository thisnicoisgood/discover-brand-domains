# Discover Brand Domains

## 确定检索范围

- 从用户的行业、地区、语言和目标开始。分别记录候选品牌、网站入口和公开商务联系方式。需要广告合作时，查明联系方式属于平台、代理商还是刊登广告的频道。
- 有旧表时先读取最新版本，建立域名和品牌基线。用户提供过的名字、域名、频道和别名作为留出的验证样本。品牌盲搜时只使用通用词，事后再核对是否命中样本。
- 默认使用远程搜索。通过多个索引、公开目录或数据源扩大覆盖。仅在服务明确给出底层引擎时记录引擎名。同一个服务的不同检索模式记录为模式。

## 并行发现候选

| 入口 | 操作 |
|---|---|
| 网页搜索 | 按语言、地区和业务词组合查询。体育业务可分别用体育投注、滚球、盘口、足球贴士、运彩、sportsbook。综合平台另搜电子、真人、棋牌、捕鱼、体育。按需要翻页，记录实际查询和范围。 |
| 行业名录 | 从赔率供应商的博彩公司列表、比较站和当地监管名录提取品牌及域名。使用牌照来源核对特定地区的授权和运营主体。 |
| Telegram 原帖 | 从公开的频道简介、置顶帖、品牌发布帖和冠名广告正文提取域名。搜索 国内线路、海外线路、备用网址、官方频道、客服、会员聊天群、官方招商。用多组短查询，也试繁体和近义词。 |
| Telegram 目录 | 分别查 Nicegram、TGFind、Telemetr 等公开索引及其体育、游戏、新闻分类。独立搜索频道简介和帖子，覆盖原帖未被网页索引的场景。 |
| 关联频道反查 | 从公开目录的提及、转发、赞助或广告主栏目识别品牌。沿品牌频道继续找同帖列出的线路，并核对名称是否曾变更。对同一 Telegram 频道的镜像、不同语言版本和相同转发归并来源。 |
| 广告合作反查 | 组合行业词与广告合作、媒体包、刊登广告。摘录公开商务入口和明确的投放条件。客服、代理招募、频道广告和网站广告各自注明。 |

## 开奖、数据与工具站盲搜

- 任务范围包含相关网站时，单独运行数据与工具站查询。用行业词或玩法别名搭配站点功能词，分组搜索实时开奖、历史记录、走势、统计、数据下载和开放接口。查找首页及提供实质内容的历史页、走势图、API 文档。
- 加拿大28示例：先分别跑 `"PC28" "开奖网" "数据"`、`"加拿大28" "实时开奖" "历史记录"`、`"PC蛋蛋" "走势"` 和 `"加拿大28" "开奖" "API"`。另跑 PC2.0、PC2.8、PC 网盘、满赔等平台或公群查询。每组按各自结果上限收集，避免高频推广帖挤占数据站的结果。
- 从命中的数据页核对站点名和具体功能。首页与 API、走势、历史等子页面按域名合并，保留证据最明确的页面。区分开奖或数据站、综合入口、游戏平台和 Telegram 线索。页面有投注外链时，记录链接指向的域名和可见关系。
- 漏站排查依次记录域名定向核验、无域名查询复跑、旧表完整域名比对。能复跑命中时记录查询词和来源。只有原始检索记录能证明当时的返回或排序，缺少记录时写明原因未能完全确定。

## Telegram 推广帖盲搜

- 将两三个行业词与推广帖常用词组合，分别在 `tg.me`、`telemetr.io` 等公开索引查帖子正文。轮换「综合游戏平台」「游戏客服」「免注册」「人民币台」「合作伙伴计划」等词，每组使用一个推广词或短语。保留少量宽查询，避免把只经营单一类别的平台漏掉。
- 可直接复用 `site:tg.me "电子" "捕鱼" "棋牌" "综合游戏平台"`、`site:tg.me "棋牌" "电子" "捕鱼" "游戏客服"` 和 `site:telemetr.io "棋牌" "捕鱼" "免注册" "人民币台"`。查询中不带已知品牌、域名或账号。先查看命中的单条推广帖，再查该频道的公告、置顶帖和转发原文。新闻频道的冠名和付费广告也可提供候选，注意逐帖确认域名属于哪一个广告主。
- 查看帖子正文、按钮的公开链接、配图文字和二维码。分别记录首次命中来源和确认域名的来源。由通用词找到帖子后，再用其中的品牌、频道或客服账号反查域名，仍可记为盲搜发现。用户先提供品牌或域名时，记为定向核验。
- 与旧表的域名列按完整域名精确比对。分别统计新增品牌、平台域名、同品牌其他入口及相关站点。历史广告标注日期，域名有公开推广证据时记录为候选，页面可读性和安全状态各自核查。

## 提取、核查、对比

1. 保存原始来源、查询、命中页面、可辨认的原帖日期与核查日期。从正文和外链提取域名，同时识别没有协议的域名和裸域名。只保留在明确品牌语境里出现的入口。排除钱包、推广中转、下载地址和无关引用，范围式域名未单独核实时保留为文字备注。
2. 域名用公共后缀规则归并，保留原始主机与地区入口。凭同一条公开简介、公告或站方页面明确列出的关系归并品牌。名称相似、同 IP、同证书或数字编号可用于提线索，品牌归属仍须另核。对冠名只确认冠名关系。
3. 分别核查域名归属、页面可读性、正文是否证实目标业务、恶意软件或钓鱼信誉。检查主域、公开栏目和跳转；把抓取失败、JS 框架、历史快照、地区限制分别标明。没有可靠安全判定时记录待核。来源为频道自述时标明。
4. 合并各来源的并集，单独标记交集。按方法记候选域名、相对旧表净增、同品牌入口、页面可读和目标业务已验证。对比实验使用相同的结果上限，写明样本、人工筛选边界、重复和未核项。若只核对部分命中，给出可复核的下限。未跑过的方法保持未测试。
5. 输出 Excel 时把「全部网站」设为首页。一域名一行，显示网站、域名、类型、状态、公开联系、合作入口。将来源、核查详情和搜索对比放在后页。待核域名可用纯文本，链接指向公开证据。保留原记录并验证筛选范围、链接与计数。

## 示例

未知中文综合娱乐平台时，独立运行 `site:nicegram.app/hub/channel "国内线路" "海外线路"` 和 `site:tgregister.com/channel "官方招商" 体育 备用网址`。第一条看简介，第二条同时检查「提及」区。若一个频道列出国内和海外两条线，则记 1 个品牌、2 个域名。若两站正文均未读取，给出 2 条待核线索。
